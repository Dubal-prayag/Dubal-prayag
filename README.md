## 📌 Featured Projects

### 🖱️ Hand Gesture Mouse Control  
**Computer Vision | MediaPipe | OpenCV | PyAutoGUI**  
🔗 https://github.com/Dubal-prayag/Control-your-mouse-using-hand-gestures-via-webcam  

- Control your entire mouse (move, click, scroll) using only hand gestures via webcam  
- 🖐️ Real-time hand landmark detection using MediaPipe  
- 🖱️ Pinch gesture → left/right click, index finger → cursor movement  
- ⚡ Adjustable scroll speed and pinch sensitivity via hotkeys
