### 🖱️ Hand Gesture Mouse Control
**Computer Vision | MediaPipe | OpenCV | PyAutoGUI**
🔗 [github.com/Dubal-prayag/Control-your-mouse-using-hand-gestures-via-webcam](https://github.com/Dubal-prayag/Control-your-mouse-using-hand-gestures-via-webcam)

> Control your entire mouse — move, click, scroll — using only hand gestures via webcam. No physical mouse needed.

- 🖐️ Real-time hand landmark detection using MediaPipe
- 🖱️ Pinch gesture → left/right click, index finger → cursor movement
- ⚡ Adjustable scroll speed and pinch sensitivity via hotkeys
- 🪟 Platform-aware: Windows uses `ctypes` for smooth scroll
- 🔴 Press `ESC` to exit anytime

### 🔊 Smart Volume Control v3
**Computer Vision | OpenCV | MediaPipe | Pycaw**
🔗 [github.com/Dubal-prayag/Smart-Volume-Control-v3](https://github.com/Dubal-prayag/Smart-Volume-Control-v3)

> Control your system volume in real-time using hand gestures — no keyboard, no remote.

- 👌 Pinch distance between thumb and index finger maps to volume level
- 🎚️ Live volume bar rendered on screen via OpenCV
- ⚡ Low-latency real-time inference using MediaPipe hand landmarks
- 🪟 Windows audio control via Pycaw
